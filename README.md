# FakeVR

Статус "Online using VR" в стиме без вр шлема.

Ставит в SteamVR виртуальный шлем и держит SteamVR в фоне со скрытыми окнами.

## Что нужно

- Windows 10/11
- Steam
- SteamVR (бесплатный, есть в библиотеке стима)

## Установка

1. Качаешь FakeVR.zip из [Releases](../../releases), распаковываешь
2. Запускаешь FakeVR.exe (если вылезет SmartScreen - Подробнее -> Выполнить в любом случае)
3. Жмешь Да, дальше он все сам поставит, сделает ярлыки на рабочем столе и спросит про автозапуск

## Использование

- "VR статус ВКЛ" - включить
- "VR статус ВЫКЛ" - выключить
- удалить - запустить FakeVR.exe еще раз и нажать Нет, или `FakeVR.exe --uninstall`

Если SteamVR обновится и что то слетит, прога сама все починит при следующем запуске.

Перед изменением настроек SteamVR делаются бэкапы (.bak), при удалении все возвращается как было.

## Сборка

```
sudo apt-get install -y g++-mingw-w64-x86-64 python3 curl
./build.sh
```

exe в релизах собирается через GitHub Actions из этого кода.
